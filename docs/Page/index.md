# Sentrio

Predictable audio routing and BusyLight automation for macOS.

[Download the latest release](https://github.com/YunaBraska/Sentrio/releases/latest) | [Documentation](documentation.html) | [Install](install.html)

## What it does

- Switches audio input and output devices by your priority order.
- Restores per-device output, input and alert volumes.
- Keeps device names, icons and battery information visible.
- Automates BusyLight behavior, including local HTTP control and macOS integrations.
- Exports and imports settings backups.

## Updates

Direct downloads are Developer-ID signed and notarized. Automatic updates will be available through the external distribution channel. Mac App Store builds will use the App Store update channel.
